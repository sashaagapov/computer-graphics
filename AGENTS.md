# Computer Graphics repository guidance

## Scope

This repository contains Computer Graphics laboratories. Keep source code, tests, required input images in `assets/input`, and required reports. Do not commit virtual environments, caches, IDE state, generated output, temporary screenshots, or report-building scratch files unless they are explicitly required deliverables.

## Before committing

1. Review the changed laboratory and run its tests from that laboratory directory.
2. Inspect new images and reports to confirm that they are required course materials.
3. Stage only reviewed source, tests, inputs, and required reports.
4. Keep local tooling and generated intermediate files ignored.

## Commit and push quality

- Make each commit focused on one finished laboratory or a single coherent improvement.
- Use concise, factual messages such as `Add image processing lab 5`.
- Avoid vague messages, generic boilerplate, and irrelevant references to tools.
- Do not state untrue authorship, results, or verification claims.
- Do not rewrite published history merely to change the appearance of older commits.
- Push only after tests and the staged diff have been reviewed.
