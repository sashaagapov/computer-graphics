# Скріншоти для звіту ЛР4

Відкрийте `labs/lab04/main.py`, виберіть будь-яке невелике кольорове зображення PNG або JPG через **Choose images**. Для операцій, що зберігають файл, виберіть будь-яку папку через **Choose output folder**.

1. **Головне вікно.** Запустіть програму; має бути видно список операцій ЛР4 у полі **Operation**.
2. **Show original.** Виберіть `Show original` і натисніть **Run processing**; у новому вікні видно зображення та його розмір у пікселях.
3. **Brightness matrix.** Виберіть `Brightness matrix`; для компактного скріншота краще взяти маленьке зображення. У новому вікні має бути матриця цілих значень.
4. **Brightness histogram.** Виберіть `Brightness histogram`; у новому вікні має бути графік з віссю яскравості 0..255.
5. **Grayscale result.** Виберіть `Grayscale`, вкажіть папку результатів, натисніть **Run processing**; відкрийте створений файл із суфіксом `_grayscale.png`.
6. **Binarization.** Виберіть `Binarization`, залиште **Threshold = 128**, вкажіть папку результатів і натисніть **Run processing**; відкрийте файл `_binary.png`.
7. **Negative result.** Виберіть `Negative`, вкажіть папку результатів, натисніть **Run processing**; відкрийте файл `_negative.png`.
8. **Grayscale histogram.** Виберіть `Grayscale histogram` і натисніть **Run processing**; у новому вікні має бути гістограма для grayscale-зображення.
